This read me in addition to the google drive process PDF will serve as documentation for this class exercise. VSCodium was used to build and edit the website locally.  Using VSCodium three files were created that include an index.js, main.js, and a server.js.  These files were loaded to GitHub as a reference link only and included in the Google drive.  The code lives on a server using Digital Ocean for hosting.  The index.html and main.js serve as the front end of the website in the public folder.  The server.js is the back end of the website.  Other files that are not present in the GitHub and were included in the Digital Ocean folder are node_modules, package-lock.json, and package.json.  The files were uploaded and revised in VSCodium locally.  CyberDuck was used to load the files to Digital Ocean using SFTP.  Once loaded the server was stopped with ^C and then restarted using node server.js.
